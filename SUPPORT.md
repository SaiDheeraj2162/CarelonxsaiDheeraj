# Support

For usage questions, start with the [README](README.md) and [demo walkthrough](docs/demo-walkthrough.md). For product boundaries and safety constraints, read [assumptions and limitations](docs/assumptions-and-limitations.md).

After the repository is published, use GitHub Discussions for general questions if Discussions is enabled. Use an issue for a reproducible defect or a scoped enhancement. Do not post security concerns, credentials, real patient/member data, or confidential partner information publicly; see [SECURITY.md](SECURITY.md).
