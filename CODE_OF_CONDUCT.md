# Code of Conduct

## Our pledge

We want participation in this project to be respectful, constructive, and free from harassment. We welcome contributors regardless of background, identity, experience level, or perspective.

## Expected behavior

- Use respectful, professional language.
- Focus critique on ideas and work, not people.
- Respect privacy and never share sensitive, personal, clinical, or proprietary information.
- Accept constructive feedback and help create an inclusive environment.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, disclosure of private information, or any conduct that makes participation unsafe is not acceptable.

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code. Report concerns privately to a repository maintainer. Maintainers will review reports promptly and handle them as confidentially as practical.

This policy is informed by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
